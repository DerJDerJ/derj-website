Auf dieser Website ist ein SoundCloud-Player eingebunden (iframe). Beim Aufruf werden technische Daten (u.a. IP-Adresse) an SoundCloud Ltd. übermittelt, um den Inhalt darzustellen. SoundCloud verarbeitet diese Daten gemäß seiner eigenen Datenschutzerklärung. Rechtsgrundlage ist Art.6 Abs.1 lit.f DSGVO (berechtigtes Interesse an der Bereitstellung von Audio-Inhalten).

Newsletter (Underground-Bereich)

Im passwortgeschützten Bereich kann eine E-Mail-Adresse für den Newsletter eingetragen werden. Die Anmeldung erfolgt via E-Mail (mailto-Link). Die Adresse wird ausschließlich zur Versendung von Informationen über Underground-Events verwendet. Es erfolgt keine Speicherung auf einem Server ohne ausdrückliche Zustimmung.

Cookies

Diese Website verwendet keine eigenen Cookies. Der eingebettete SoundCloud-Player kann Cookies setzen, die von SoundCloud gesteuert werden. Du kannst SoundCloud-Cookies in den Einstellungen deines Browsers verwalten oder den SoundCloud-Player durch Nicht-Aufruf vermeiden.
